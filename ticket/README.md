# アイバレエスタジオ 発表会 チケット申込システム

発表会のチケット申込をオンラインで受け付け、Google スプレッドシートに自動で記録するシステムです。来年以降もこのファイル一式をベースに修正して再利用できます。

## 公開URL

- 申込ページ: https://ticket.aiballetstudio.net/ticket/index.html
- 独自ドメイン: ticket.aiballetstudio.net（サブドメイン）

## ファイル構成

| ファイル | 役割 |
|----------|------|
| `index.html` | 申込フォーム＋チケット画面の本体（これを編集する） |
| `moji.png` | ヘッダー・チケットのスタジオロゴ画像 |
| `rogo.png` | 公演情報カード・チケットのバレリーナのシルエット画像 |
| `README.md` | この説明書 |

## 全体の仕組み

```
申込者のスマホ/PC
   ↓ 申込ボタン
index.html（GitHub Pagesで公開）
   ↓ データ送信
Google Apps Script（GAS）
   ↓ 書き込み
Google スプレッドシート（主催者が確認）
```

- データベースは使わず、Google スプレッドシートに記録します
- 費用はすべて無料（GitHub Pages / Google Sheets / GAS）

## 来年の修正ポイント（index.html 内）

### 1. 公演情報（タイトル・日時・会場・演目）

ファイル内の「公演情報カード」と「チケット」の2箇所に同じ内容があります。両方直してください。検索して探すのが早いです。

- タイトル: `第2回発表会` を検索
- 日付: `2026年11月8日（日）` を検索
- 時間: `開場 14:30 ／ 開演 15:00（予定）` を検索
- 会場: `おにクル ゴウダホール` を検索
- 演目: `バレエコンサート` `ピーター・パン` を検索

### 2. デザインの色

ファイル上部の `:root {` の中にある色変数（CSS変数）を変えると、全体の配色が一括で変わります。

- 今年は明るい緑（ピーター・パンのイメージ）
- 主な色: `--pink`（メインの明るい緑）、`--navy`（濃い緑）、`--gold`（金のアクセント）
- 変数名は「pink」「navy」のままですが、中身の色コードを変えれば見た目が変わります

### 3. シルエット画像

- `rogo.png` を差し替えると、公演情報カードとチケットのシルエットが変わります
- 画像は「黒いシルエット＋白背景」のものを用意してください（CSSで白く反転表示しています）
- 左右反転は `.silhouette-inline` の `scaleX(-1)` で制御

### 4. 注意書き

- `ご入場は出演者のご家族` を検索すると、公演情報カードの注意書きが見つかります

## Google 側の設定（通常は変更不要）

### Google Apps Script（GAS）のURL

`index.html` 内の `GAS_URL` という変数にGASのURLが設定されています。

- 同じスプレッドシートを使い続ける場合: 変更不要
- 新しいスプレッドシートに変える場合: 新しいGASをデプロイして、そのURLを `GAS_URL` に貼り替える

### スプレッドシートの列構成

```
No. | 申込日時 | 代表者名 | 来場者名 | 年齢区分 | 目的 | 出演者名 | メール | 体験案内メール | 区分 | 合計人数 | 端末種別 | ブラウザ識別ID
```

- 代表者とお連れ様は1人1行で記録されます
- 「区分」列で「代表者」「お連れ1」「お連れ2」…を判別
- 「ブラウザ識別ID」で同じ端末からの重複申込を見分けられます

### GASのコード（スプレッドシートの「拡張機能」→「Apps Script」）

GASは1リクエストで代表者＋お連れ様を一括で記録し、排他ロックで同時申込の競合を防いでいます。コードを変更したら必ず「新しいバージョン」で再デプロイしてください。

## 更新のやり方（Kiroに依頼する場合）

1. 修正したい内容をKiroに伝える
2. Kiroが `index.html` を編集してGitHubにプッシュ
3. 1〜2分後に公開URLに反映される（反映されない時はブラウザを強制リロード）

## 更新のやり方（手動の場合）

```powershell
cd c:\kiro
git add ticket/index.html
git commit -m "変更内容のメモ"
git push
```

## 発表会終了後にページを閉じたいとき

GitHubリポジトリの「Settings」→「Pages」で Source を「None」にすると公開停止できます。設定・ファイルは残るので、来年また公開できます。
